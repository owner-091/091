# Train Game

Unity 기반 **탑뷰 도트 스타일 열차 여행 게임**의 초기 개발 저장소입니다.

## 확정된 기본 방향

- 화면 형식: 2D 탑뷰
- 시각 방향: 픽셀/도트 아트
- 플레이어 캐릭터: 열차의 차장
- 기본 생활 공간: 열차 내부
- 장기 진행: 노드형 노선을 따라 세계를 여행
- 패배 조건: 없음. 선택에 따라 사건과 결말이 달라지는 구조
- 열차는 파손되지 않으며 플레이어 캐릭터가 아닙니다.

플레이어는 차장을 직접 움직여 열차 내부에서 승객과 대화하고, 화물·손님 상태·접객·승무원 배치·식당 상태 등을 확인합니다.

## 이야기와 여행의 기본 구조

역마다 2~3개의 서브 이벤트와 1개의 메인 이벤트를 구성합니다.

정차 시간은 실제 랜덤 타이머가 아니라 각 역의 사건 진행에 맞춰 설계하고, 플레이어에게는 운행 상황에 따라 정차 시간이 달라지는 것처럼 보이게 합니다.

메인 이벤트 마지막의 선택은 다음 노선과 목적지를 결정하는 데 사용합니다. 이동 중에는 메인 이벤트보다 작은 열차 내부 사건과 승객 대화가 발생하며, 대화는 다음 역의 사건에 대한 복선으로도 활용합니다.

## 현재 포함된 기반

- StationData — 역 데이터
- RouteData / RouteStop — 노선 및 정차 지점
- JourneyEventData — 향후 사건 시스템용 기본 데이터
- TrainMovementController — 노선 이동 프로토타입용 기반
- GameFlowController — 여행 흐름의 초기 기반
- ConductorTopDownController — 차장의 2D 탑뷰 이동
- Tools > Train Game > Create Top-Down Demo Scene — 탑뷰 열차 내부 프로토타입 자동 생성
- EditMode 테스트 어셈블리

## 처음 실행하기

1. 저장소를 clone합니다.
2. Unity Hub에서 프로젝트를 엽니다.
3. 스크립트 컴파일이 끝나면 **Tools > Train Game > Create Top-Down Demo Scene**을 실행합니다.
4. 생성된 Assets/TrainGame/Scenes/TrainInteriorPrototype.unity를 엽니다.
5. Play를 누릅니다.
6. 방향키 또는 WASD로 차장을 움직입니다.

현재 데모는 실제 아트가 아니라 Point 필터링된 임시 픽셀 스프라이트를 자동 생성하여 사용합니다. 따라서 아트 에셋이 없어도 탑뷰 이동과 공간 크기를 먼저 검증할 수 있습니다.

## 현재 프로토타입에서 확인할 것

첫 단계에서는 다음 네 가지만 확인합니다.

- 탑뷰에서 차장 이동이 자연스러운가
- 한 객차 안에서 이동/충돌 감각이 적절한가
- 승객과 시설을 배치할 공간이 충분한가
- 추후 여러 객차를 연결하기 좋은 좌표/스케일인가

## 다음 개발 순서

1. 여러 객차를 이어 붙일 수 있는 열차 내부 구조
2. 차장-NPC 상호작용 범위와 상호작용 버튼
3. 승객 대화용 최소 대화창
4. 정차/출발/운행 중 상태 머신
5. 노드형 노선 데이터
6. 역 도착과 출발 전환
7. 화물·승객·승무원·식당 관리 인터페이스
8. 사건 시스템과 메인 이벤트 분기

이벤트 내용 자체는 열차 내부 이동과 여행 구조가 안정된 이후 구체화합니다.
